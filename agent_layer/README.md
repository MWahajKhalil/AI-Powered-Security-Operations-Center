# AI Agent Layer

This directory will contain the reasoning and planning logic of our AI security agent.

## Responsibility
- **Intent Parsing**: Taking unstructured user security prompts and identifying goals.
- **Tool Selection**: Picking which MCP tools to execute based on available tools.
- **Workflow Orchestration**: Chain-of-thought execution of tools to solve multi-step investigations.
- **Response Synthesis**: Explaining complex technical outputs of tools in simplified, action-oriented natural language.
