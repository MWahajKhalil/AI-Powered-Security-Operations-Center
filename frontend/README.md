# Frontend Dashboard

This directory will contain the user interface for our SOC Dashboard. It will be built using Next.js, vanilla CSS for dynamic, highly refined modern aesthetics, and Recharts for interactive threat visualizations.

## Key Features
- **Interactive Chat Interface**: Chat with the security agent.
- **Tool Execution Console**: Real-time logging showing which MCP tools the agent is executing.
- **Investigation History**: List of past analyzed events.
- **Security Visualizations**: Graphs showing alert distributions, threat levels, and network statistics.
